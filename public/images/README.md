# 圖片替換清單（Golf R 主題）

把檔案放到這個資料夾，**檔名照下面用、直接覆蓋舊檔**，程式碼不需要改動。
每個位置在圖片載入前 / 缺圖時，背後都墊了碳纖維紋理，不會破版。

| 檔名 | 用途 | 建議尺寸 / 比例 | 內容建議 |
|---|---|---|---|
| `hero.jpg` | 首頁主視覺全幅背景（多層視差、壓暗到 ~34%） | 2400×1600，橫 | Golf R 前 45 度或行進間，暗調 |
| `design.jpg` | 設計區右欄直式大圖（灰階、視差，桌機高達 120vh） | 1600×2000，直 | 碳纖維飾板 / 輪圈 / 車側鈑件 / 座艙 |
| `reserve.jpg` | 預約區整條背景（灰階、壓到 ~16%、視差） | 2400×1400，橫 | Golf R 車尾 / 停車場 / 道路 |
| `blog-turbo.jpg` | 專欄封面「渦輪」 | 1600×1000，16:10 | 引擎室 / 渦輪 / 進氣 |
| `blog-brakes.jpg` | 專欄封面「煞車」 | 1600×1000，16:10 | 輪圈 + 卡鉗特寫 |
| `blog-shifter.jpg` | 專欄封面「雙離合」 | 1600×1000，16:10 | 方向盤 / 換檔撥片 / 駕駛艙 |

- 格式 `.jpg`，單張建議 < 500 KB（`hero` 可放寬到 800 KB）。
- 最少只換 `blog-*` 三張也能看；`hero` / `design` / `reserve` 不換的話會直接顯示碳紋底。
